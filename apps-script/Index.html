Template Google Docs

Template surat yang sedang digunakan. Klik Edit untuk membuka Google Docs bila perlu menyesuaikan redaksi. Jangan hapus placeholder seperti {{NOMOR}} atau {{NAMA_KETUA}}.

Kop dan ornamen asli HVC dipasang otomatis dari Media.gs. Tombol ini memperbarui bagian atas dan bawah pada kelima template tanpa mengubah isi surat.

🖼 Latar Surat HVC Full A4

Kop dan ornamen menyatu sebagai gambar latar di belakang tulisan pada kertas A4 (210 × 297 mm). Pengaturan awal watermark pada Google Docs master dilakukan sekali.

1. Klik Siapkan Master A4.
2. Buka gambar latar, lalu di Google Docs master pilih Sisipkan → Watermark → Gambar. Pilih gambar itu, nonaktifkan Pudar/Faded, dan sesuaikan skala hingga menutup kertas.
3. Klik Terapkan Latar A4 ke 5 Template. Isi template lama dipertahankan; salinan cadangan otomatis dibuat.
