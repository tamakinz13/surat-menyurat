# Membuat repository GitHub Private untuk cadangan kode HVC

1. Buka https://github.com/new.
2. Repository name: `hvc-admin-private` (contoh).
3. Pilih **Private** (penting).
4. Klik **Create repository**.
5. Ekstrak ZIP ini dan unggah file/folder hasil ekstrak ke repository.
6. Klik **Commit changes**.
7. Repository ini hanya untuk cadangan kode, bukan untuk GitHub Pages.
8. **Aplikasi resmi tetap di Google Apps Script**. Jangan mengunggah data anggota atau rahasia.

Jika suatu hari Anda ingin mengedit aplikasi memakai GitHub + clasp, itu perlu proses sinkronisasi tambahan. Paket ini tidak diam-diam menulis ke akun Google Anda.
